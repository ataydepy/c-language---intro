# 🖥️ Programação em Linguagem C

Este repositório contém todos os códigos-fonte, exercícios e projetos desenvolvidos durante a disciplina de **Programação** do curso de [Nome do seu Curso] na [Nome da sua Faculdade]. 

Apesar de ser a porta de entrada para a programação, o conteúdo aborda desde a lógica básica até conceitos avançados de gerenciamento de memória e estruturas de dados em C.

---

## 🚀 Conteúdo do Repositório

O aprendizado está organizado por tópicos evolutivos. Cada pasta contém exemplos teóricos e listas de exercícios práticos:

* **01. Fundamentos**: Sintaxe básica, tipos de dados (`int`, `float`, `char`), entrada e saída (`printf`, `scanf`).
* **02. Estruturas Condicionais**: Tomada de decisão com `if`, `else if`, `else` e `switch-case`.
* **03. Estruturas de Repetição**: Loops e laços de repetição com `while`, `do-while` e `for`.
* **04. Vetores e Matrizes**: Arrays unidimensionais e multidimensionais para manipulação de tabelas e listas de dados.
* **05. Strings**: Manipulação de cadeias de caracteres usando a biblioteca `<string.h>`.
* **06. Funções e Procedimentos**: Modularização de código, escopo de variáveis e passagem de parâmetros (por valor e por referência).
* **07. Estruturas de Dados Customizadas**: Criação de tipos personalizados com `struct`, `union` e `typedef`.
* **08. Ponteiros**: Entendimento de endereços de memória, operadores `*` e `&`, e aritmética de ponteiros.
* **09. Alocação Dinâmica de Memória**: Uso avançado de funções como `malloc()`, `calloc()`, `realloc()` e `free()`.
* **10. Manipulação de Arquivos**: Leitura e escrita de dados em arquivos de texto (`.txt`) e binários.

---

## 🛠️ Ferramentas Utilizadas

* **Linguagem:** C (Padrão ANSI / C11)
* **Compilador:** GCC (GNU Compiler Collection)
* **IDE Recomendada:** VS Code (com a extensão *C/C++* da Microsoft) ou Code::Blocks

---

## ⚙️ Como Executar os Códigos

Para compilar e rodar qualquer arquivo deste repositório localmente via terminal, siga os passos abaixo:

1. **Clone o repositório:**
   ```bash
   git clone https://github.com
   ```
2. **Acesse a pasta do exercício:**
   ```bash
   cd nome-da-pasta
   ```
3. **Compile o arquivo `.c`:**
   ```bash
   gcc nome_do_arquivo.c -o programa
   ```
4. **Execute o programa gerado:**
   * No Linux/macOS:
     ```bash
     ./programa
     ```
   * No Windows:
     ```bash
     programa.exe
     ```
